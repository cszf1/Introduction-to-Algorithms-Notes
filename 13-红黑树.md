## 本章导读

### 🎯 一句话概括
> **红黑树是一种"自平衡"的二叉搜索树，通过红黑两种颜色标记和一套旋转规则，让树的高度始终保持在 O(log n)，从而保证所有操作都高效稳定。**

### 🤔 为什么需要红黑树？

| 数据结构 | 查找复杂度 | 插入复杂度 | 删除复杂度 | 自动平衡 |
|:--:|:--:|:--:|:--:|:--:|
| 普通二叉搜索树 | O(h) | O(h) | O(h) | ❌ 可能退化 |
| **红黑树** | **O(log n)** | **O(log n)** | **O(log n)** | **✅ 自动保证** |
| AVL树 | O(log n) | O(log n) | O(log n) | ✅ 严格平衡 |

**红黑树的核心优势**：
- 插入/删除只需要 O(1) 次旋转（最多2次）
- 而AVL树可能需要 O(log n) 次旋转
- 实际应用中，红黑树的综合性能往往优于AVL树

## 13.1 红黑树的定义与性质

### 📖 什么是红黑树？

**红黑树（Red-Black Tree）** 是一种自平衡的二叉搜索树，通过节点的颜色标记和特定的平衡规则，保证树的高度始终为 O(log n)。

### 🎨 红黑树的5大性质（必须牢记！）

```
┌─────────────────────────────────────────────────────────┐
│  红黑树的5条性质（RB-Tree Properties）：                  │
│                                                          │
│  【性质1】每个节点要么是红色，要么是黑色                  │
│     → 只有两种状态，非此即彼                             │
│                                                          │
│  【性质2】根节点必须是黑色                                │
│     → 树的"根基"必须稳固                                │
│                                                          │
│  【性质3】每个叶节点(NIL)是黑色                           │
│     → NIL是"哨兵节点"，代表空位置                        │
│     → 注意：这里的叶节点不是传统意义上的叶子              │
│                                                          │
│  【性质4】红节点的子节点必须是黑色（不能有红红相连）       │
│     → 红节点的左右孩子 = 黑色                            │
│     → 作用：限制红节点的密度，防止过度集中                │
│                                                          │
│  【性质5】从任一节点到其每个叶子的路径黑色高度相同        │
│     → "黑色高度"：路径上黑色节点的数量                   │
│     → 作用：保证所有路径长度相对均衡                      │
│                                                          │
│  这5条规则共同保证了树的"近似平衡"！                     │
└─────────────────────────────────────────────────────────┘
```

│           NIL     NIL           [22]B                  │
│                                 /    \                 │

│                                                        │

## 13.2 黑色高度与高度约束

### 📐 黑色高度（Black Height）

**定义**：从某个节点（不包括该节点本身）到任意叶节点的任意路径上的黑色节点数量（不包括 NIL 哨兵节点）。

```
┌────────────────────────────────────────────────────────┐
│  黑色高度计算示例：                                      │
│                                                        │
│                        [15]B                           │
│                       /     \                           │
│                      /       \                          │
│                    [6]R       [18]B                     │
│                   /    \                                 │
│                  /      \                               │
│               [3]B      [7]B                            │
│                                                        │
│  节点15的黑色高度bh(15) = ?                              │
│                                                        │
│  路径15→3→NIL：15(B),3(B) = 2个（不含15）              │
│  路径15→6→7→NIL：6(B),7(B) = 2个（不含15）             │
│  路径15→18→NIL：18(B) = 1个（不含15）                  │
│                                                        │
│  取最小值：bh(15) = 1                                    │
│                                                        │
│  ⚠️ 注意：计算时从子节点开始数，不包含当前节点！         │
└────────────────────────────────────────────────────────┘
```

### 🎯 高度约束定理

**定理13.1**：对于有 n 个节点的红黑树，高度最多为 `2log₂(n+1)`。

**证明思路**：

```
┌─────────────────────────────────────────────────────────┐
│  高度约束定理证明：                                      │
│                                                          │
│  第一步：从黑高推导子树规模                              │
│  ┌──────────────────────────────────────────┐          │
│  │  对于任意节点x，以x为根的子树至少包含：     │          │
│  │                                          │          │
│  │  2^(bh(x)) - 1 个内部节点                 │          │
│  │                                          │          │
│  │  为什么？归纳证明：                        │          │
│  │  - 如果bh(x) = 0（没有黑色子节点）        │          │
│  │    → 最小子树只有NIL → 2^0-1 = 0 ✓       │          │
│  │  - 假设左右子树的命题成立                  │          │
│  │  → 左子树≥2^(bh(x)-1)-1（因为孩子黑高≥bh(x)-1）│     │
│  │  → 右子树≥2^(bh(x)-1)-1                  │          │
│  │  → 总节点≥2×[2^(bh(x)-1)-1]+1=2^bh(x)-1 ✓│          │
│  └──────────────────────────────────────────┘          │
│                                                          │
│  第二步：根节点的黑高与高度的关系                         │
│  ┌──────────────────────────────────────────┐          │
│  │  根节点的黑高bh ≥ h/2                     │          │
│  │                                          │          │
│  │  证明：                                   │          │
│  │  - 任意路径黑高相同                       │          │
│  │  - 最短路径：全黑，h/2 ≤ 黑高 ≤ h        │          │
│  │  - 最长路径：红黑交替，最多2×黑高        │          │
│  │  → h ≤ 2×黑高                            │          │
│  │  → 黑高 ≥ h/2                            │          │
│  └──────────────────────────────────────────┘          │
│                                                          │
│  第三步：综合得出高度上界                                │
│  ┌──────────────────────────────────────────┐          │
│  │  n ≥ 2^(bh) - 1 ≥ 2^(h/2) - 1             │          │
│  │                                          │          │
│  │  整理：n + 1 ≥ 2^(h/2)                   │          │
│  │  → h/2 ≤ log₂(n+1)                       │          │
│  │  → h ≤ 2log₂(n+1)  ✓                     │          │
│  └──────────────────────────────────────────┘          │
│                                                          │
│  💡 结论：红黑树的高度始终是 O(log n)！                  │
└─────────────────────────────────────────────────────────┘
```

## 13.3 旋转操作（左旋和右旋）

### 🔄 旋转的核心思想

**旋转**：在不破坏二叉搜索树性质的前提下，调整树的结构，使某些子树的高度降低，同时使另一些子树的高度升高。

```
┌─────────────────────────────────────────────────────────┐
│  旋转 = 树结构的"微调手术"                               │
│                                                          │
│  ┌────────────────┐       ┌────────────────┐          │
│  │    左旋 (L)     │ ←→   │    右旋 (R)     │          │
│  │   Rotate Left  │       │   Rotate Right │          │
│  └────────────────┘       └────────────────┘          │
│                                                          │
│  【左旋】将右子树上移，父节点下沉为左子树                 │
│  【右旋】将左子树上移，父节点下沉为右子树                 │
│                                                          │
│  ⚠️ 注意：旋转不会改变中序遍历的顺序！                   │
└─────────────────────────────────────────────────────────┘
```

### 📊 过程图解：左旋（Left Rotate）

```
左旋操作详解：将节点 x 向左下方旋转
┌────────────────────────────────────────────────────────┐
│                                                        │
│  【旋转前】              【旋转后】                     │
│                                                        │
│        x                    y                          │
│       / \      ←左旋→      / \                        │
│      α   y                x   γ                       │
│         / \              / \                          │
│        β   γ            α   β                         │
│                                                        │
│  关键变化：                                            │
│  - y 成为新的根节点                                    │
│  - x 变为 y 的左子节点                                 │
│  - y 的左子节点 β 变为 x 的右子节点                    │
│                                                        │
│  变化过程：                                            │
│  1. y 的左孩子 β → 成为 x 的右孩子                    │
│  2. x 的父节点 → 指向 y                                │
│  3. y → 成为新的子树的根                               │
└────────────────────────────────────────────────────────┘

左旋的Python实现：
```python
def left_rotate(T, x):
    """
    对节点 x 进行左旋
    
    旋转前：          旋转后：
        x               y
       / \      →      / \
      α   y           x   γ
         / \         / \
        β   γ       α   β
    """
    y = x.right          # y 是 x 的右孩子
    
    # 步骤1：y 的左子树 β 变为 x 的右子树
    x.right = y.left
    if y.left != T.NIL:   # 如果 β 不是哨兵节点
        y.left.parent = x
    
    # 步骤2：x 的父节点指向 y
    y.parent = x.parent
    if x.parent == T.NIL:    # x 是根节点
        T.root = y
    elif x == x.parent.left:  # x 是左孩子
        x.parent.left = y
    else:                       # x 是右孩子
        x.parent.right = y
    
    # 步骤3：y 成为 x 的父节点，x 成为 y 的左孩子
    y.left = x
    x.parent = y
```

左旋的C++实现：
```cpp

    Node* y = x->right;        // y 是 x 的右孩子
    
    // 步骤1：y 的左子树 β 变为 x 的右子树
    x->right = y->left;
    if (y->left != NIL) {      // 如果 β 不是哨兵节点
        y->left->parent = x;
    }
    
    // 步骤2：x 的父节点指向 y
    y->parent = x->parent;
    if (x->parent == NIL) {    // x 是根节点
        root = y;
    } else if (x == x->parent->left) {  // x 是左孩子
        x->parent->left = y;
    } else {                     // x 是右孩子
        x->parent->right = y;
    }
    
    // 步骤3：y 成为 x 的父节点，x 成为 y 的左孩子
    y->left = x;
    x->parent = y;
}
```

    对节点 x 进行右旋
    
    旋转前：          旋转后：
        x               y

      y   γ           α   x
     / \                  / \

    x.left = y.right
    if y.right != T.NIL:  # 如果 β 不是哨兵节点
        y.right.parent = x
    
    # 步骤2：x 的父节点指向 y
    y.parent = x.parent
    if x.parent == T.NIL:    # x 是根节点
        T.root = y

        x.parent.right = y
    else:                       # x 是左孩子
        x.parent.left = y
    
    # 步骤3：y 成为 x 的父节点，x 成为 y 的右孩子
    y.right = x
    x.parent = y
```

## 13.4 插入操作

### 📝 插入的基本步骤

红黑树的插入分为两个阶段：
1. **阶段一**：像普通二叉搜索树一样插入节点（默认插入红色节点）
2. **阶段二**：通过旋转和重新着色修复红黑树性质

```
┌─────────────────────────────────────────────────────────┐
│  插入流程图：                                            │
│                                                          │
│  ┌─────────────────────────────────────────────────┐   │
│  │ 1. 按照 BST 规则找到插入位置                      │   │
│  │ 2. 创建新节点 z，涂成红色（为什么是红色？）        │   │
│  │ 3. 将 z 插入树中                                 │   │
│  │ 4. 调用 RB-INSERT-FIXUP(z) 修复性质              │   │
│  └─────────────────────────────────────────────────┘   │
│                                                          │
│  💡 为什么要插入红色节点？                               │
│  ┌─────────────────────────────────────────────────┐   │
│  │  选择红色：                                        │   │
│  │  - 插入红色节点可能违反"红红不相连"规则          │   │
│  │  - 但不会违反"黑色高度相同"规则                  │   │
│  │                                                  │   │
│  │  选择黑色：                                        │   │
│  │  - 必然违反"黑色高度相同"规则                    │   │
│  │  - 修复更复杂                                     │   │
│  │                                                  │   │
│  │  → 所以选择红色！最多只需要 O(log n) 次修复       │   │
│  └─────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────┘
```

#### Python 实现

```python
class RBTreeNode:
    """红黑树节点"""
    def __init__(self, key, color='R'):
        self.key = key           # 节点的关键字
        self.color = color       # 节点颜色：'R'红色，'B'黑色
        self.left = None         # 左子节点
        self.right = None        # 右子节点
        self.parent = None       # 父节点


class RedBlackTree:
    """红黑树实现"""
    
    def __init__(self):
        self.NIL = RBTreeNode(key=None, color='B')  # 哨兵节点（黑色）
        self.NIL.left = self.NIL
        self.NIL.right = self.NIL
        self.NIL.parent = self.NIL
        self.root = self.NIL
    
    def left_rotate(self, x):
        """
        左旋操作
        """
        y = x.right              # y 是 x 的右孩子
        
        # 步骤1：y 的左子树成为 x 的右子树
        x.right = y.left
        if y.left != self.NIL:
            y.left.parent = x
        
        # 步骤2：x 的父节点指向 y
        y.parent = x.parent
        if x.parent == self.NIL:      # x 是根节点
            self.root = y
        elif x == x.parent.left:      # x 是左孩子
            x.parent.left = y
        else:                          # x 是右孩子
            x.parent.right = y
        
        # 步骤3：y 成为 x 的父节点，x 成为 y 的左孩子
        y.left = x
        x.parent = y
    
    def right_rotate(self, y):
        """
        右旋操作
        """
        x = y.left               # x 是 y 的左孩子
        
        # 步骤1：x 的右子树成为 y 的左子树
        y.left = x.right
        if x.right != self.NIL:
            x.right.parent = y
        
        # 步骤2：y 的父节点指向 x
        x.parent = y.parent
        if y.parent == self.NIL:      # y 是根节点
            self.root = x
        elif y == y.parent.right:     # y 是右孩子
            y.parent.right = x
        else:                          # y 是左孩子
            y.parent.left = x
        
        # 步骤3：x 成为 y 的父节点，y 成为 x 的右孩子
        x.right = y
        y.parent = x
    
    def insert_fixup(self, z):
        """
        插入修复算法
        """
        # 当z的父节点是红色时，需要修复
        while z.parent.color == 'R':
            # 情况A：z的父节点是祖父的左孩子
            if z.parent == z.parent.parent.left:
                y = z.parent.parent.right  # y = 叔叔节点
                
                # 情况1：叔叔是红色
                if y.color == 'R':
                    z.parent.color = 'B'           # 父节点涂黑
                    y.color = 'B'                   # 叔叔涂黑
                    z.parent.parent.color = 'R'      # 祖父涂红
                    z = z.parent.parent             # 向上检查祖父
                
                else:
                    # 情况2：叔叔是黑色，z是右孩子 → 转情况3
                    if z == z.parent.right:
                        z = z.parent
                        self.left_rotate(z)
                    
                    # 情况3：叔叔是黑色，z是左孩子
                    z.parent.color = 'B'            # 父节点涂黑
                    z.parent.parent.color = 'R'      # 祖父涂红
                    self.right_rotate(z.parent.parent)
            
            # 情况B：z的父节点是祖父的右孩子（镜像处理）
            else:
                y = z.parent.parent.left   # y = 叔叔节点
                
                # 情况1：叔叔是红色
                if y.color == 'R':
                    z.parent.color = 'B'
                    y.color = 'B'
                    z.parent.parent.color = 'R'
                    z = z.parent.parent
                
                else:
                    # 情况2：叔叔是黑色，z是左孩子 → 转情况3
                    if z == z.parent.left:
                        z = z.parent
                        self.right_rotate(z)
                    
                    # 情况3：叔叔是黑色，z是右孩子
                    z.parent.color = 'B'
                    z.parent.parent.color = 'R'
                    self.left_rotate(z.parent.parent)
        
        # 确保根节点始终是黑色
        self.root.color = 'B'
    
    def insert(self, key):
        """
        插入新节点
        """
        z = RBTreeNode(key=key, color='R')  # 创建红色节点
        z.left = self.NIL                   # 初始化子节点为哨兵
        z.right = self.NIL
        z.parent = self.NIL
        
        # ========== 按照BST规则找到插入位置 ==========
        y = self.NIL      # y 记录父节点
        x = self.root     # x 从根开始向下查找
        
        while x != self.NIL:
            y = x
            if z.key < x.key:
                x = x.left
            else:
                x = x.right
        
        z.parent = y      # z 的父节点
        
        if y == self.NIL:         # 树为空，z是根节点
            self.root = z
        elif z.key < y.key:       # z 插入为左子树
            y.left = z
        else:                      # z 插入为右子树
            y.right = z
        
        # ========== 调用修复算法 ==========
        self.insert_fixup(z)
```

#### C++ 实现

```cpp
#include <iostream>
#include <cstddef>

// 颜色常量
const char RED = 'R';
const char BLACK = 'B';

// 红黑树节点结构
struct RBNode {
    int key;              // 节点关键字
    char color;           // 节点颜色
    RBNode* left;         // 左子节点
    RBNode* right;        // 右子节点
    RBNode* parent;       // 父节点
    
    RBNode(int k) : key(k), color(RED),
                    left(nullptr), right(nullptr), parent(nullptr) {}
};

class RedBlackTree {
private:
    RBNode* NIL;          // 哨兵节点
    RBNode* root;         // 根节点
    
    // 左旋
    void leftRotate(RBNode* x) {
        RBNode* y = x->right;          // y 是 x 的右孩子
        
        x->right = y->left;            // y 的左子树成为 x 的右子树
        if (y->left != NIL) {
            y->left->parent = x;
        }
        
        y->parent = x->parent;         // x 的父节点指向 y
        if (x->parent == NIL) {
            root = y;
        } else if (x == x->parent->left) {
            x->parent->left = y;
        } else {
            x->parent->right = y;
        }
        
        y->left = x;                    // y 成为 x 的父节点
        x->parent = y;
    }
    
    // 右旋
    void rightRotate(RBNode* y) {
        RBNode* x = y->left;            // x 是 y 的左孩子
        
        y->left = x->right;             // x 的右子树成为 y 的左子树
        if (x->right != NIL) {
            x->right->parent = y;
        }
        
        x->parent = y->parent;          // y 的父节点指向 x
        if (y->parent == NIL) {
            root = x;
        } else if (y == y->parent->right) {
            y->parent->right = x;
        } else {
            y->parent->left = x;
        }
        
        x->right = y;                   // x 成为 y 的父节点
        y->parent = x;
    }
    
    // 插入修复
    void insertFixup(RBNode* z) {
        while (z->parent->color == RED) {
            // z的父节点是祖父的左孩子
            if (z->parent == z->parent->parent->left) {
                RBNode* y = z->parent->parent->right;  // 叔叔节点
                
                // 情况1：叔叔是红色
                if (y->color == RED) {
                    z->parent->color = BLACK;
                    y->color = BLACK;
                    z->parent->parent->color = RED;
                    z = z->parent->parent;
                } 
                else {
                    // 情况2：叔叔是黑色，z是右孩子
                    if (z == z->parent->right) {
                        z = z->parent;
                        leftRotate(z);
                    }
                    // 情况3：叔叔是黑色，z是左孩子
                    z->parent->color = BLACK;
                    z->parent->parent->color = RED;
                    rightRotate(z->parent->parent);
                }
            } 
            // z的父节点是祖父的右孩子（镜像处理）
            else {
                RBNode* y = z->parent->parent->left;   // 叔叔节点
                
                // 情况1：叔叔是红色
                if (y->color == RED) {
                    z->parent->color = BLACK;
                    y->color = BLACK;
                    z->parent->parent->color = RED;
                    z = z->parent->parent;
                }
                else {
                    // 情况2：叔叔是黑色，z是左孩子
                    if (z == z->parent->left) {
                        z = z->parent;
                        rightRotate(z);
                    }
                    // 情况3：叔叔是黑色，z是右孩子
                    z->parent->color = BLACK;
                    z->parent->parent->color = RED;
                    leftRotate(z->parent->parent);
                }
            }
        }
        root->color = BLACK;  // 保证根节点是黑色
    }
    
public:
    RedBlackTree() {
        NIL = new RBNode(0);
        NIL->color = BLACK;
        root = NIL;
    }
    
    // 插入操作
    void insert(int key) {
        RBNode* z = new RBNode(key);
        z->left = NIL;
        z->right = NIL;
        
        // 按照BST规则找到插入位置
        RBNode* y = NIL;
        RBNode* x = root;
        
        while (x != NIL) {
            y = x;
            if (z->key < x->key) {
                x = x->left;
            } else {
                x = x->right;
            }
        }
        
        z->parent = y;
        if (y == NIL) {
            root = z;
        } else if (z->key < y->key) {
            y->left = z;
        } else {
            y->right = z;
        }
        
        insertFixup(z);  // 修复红黑树性质
    }
};

## 13.5 删除操作

### 📝 删除的基本步骤

红黑树的删除比插入更复杂，因为删除黑色节点会破坏"黑色高度相同"的性质。

```
┌─────────────────────────────────────────────────────────┐
│  删除流程：                                              │
│                                                          │
│  ┌─────────────────────────────────────────────────┐   │
│  │  1. 按照 BST 规则找到要删除的节点 z               │   │
│  │  2. 记录被删除节点和替换节点的颜色信息            │   │
│  │  3. 执行实际删除                                │   │
│  │  4. 如果删除的是黑色节点，调用 DELETE-FIXUP      │   │
│  └─────────────────────────────────────────────────┘   │
│                                                          │
│  删除的三种基本情况：                                     │
│  ┌─────────────────────────────────────────────────┐   │
│  │  情况A：z 没有左子节点                            │   │
│  │  → 用 z 的右子节点（可能是 NIL）替换 z           │   │
│  │                                                  │   │
│  │  情况B：z 没有右子节点                            │   │
│  │  → 用 z 的左子节点替换 z                         │   │
│  │                                                  │   │
│  │  情况C：z 有两个子节点                            │   │
│  │  → 找后继 y（z 右子树中的最小节点）              │   │
│  │  → 用 y 替换 z，然后删除 y（转化为A或B）          │   │
│  └─────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────┘
```

### 📊 删除修复算法详解

```
┌─────────────────────────────────────────────────────────┐
│  RB-DELETE-FIXUP 修复策略（针对4种情况）：               │
│                                                          │
│  核心思想：如果删除了一个黑色节点，该路径的黑色高度会-1   │
│  解决方案：向"兄弟节点"借调（旋转+重新着色）            │
│                                                          │
│  【情况1】x 的兄弟 w 是红色                              │
│  ┌──────────────────────────────────────────────────┐ │
│  │                                                  │ │
│  │   修复前：              修复后：                  │ │
│  │                                                  │ │
│  │       [p]B                 [p]R                   │ │
│  │      /    \              /    \                  │ │
│  │    [x]B    [w]R        [x]B    [w]B              │ │
│  │            /  \                /  \              │ │
│  │          [a]  [b]            [a]  [b]             │ │
│  │                                                  │ │
│  │  操作：                                          │ │
│  │  1. w 涂黑，p 涂红                               │ │
│  │  2. 对 p 左旋                                    │ │
│  │  3. w = p.right（新的兄弟）                     │ │
│  │  4. 继续处理（变成情况2/3/4）                    │ │
│  │                                                  │ │
│  └──────────────────────────────────────────────────┘ │
│                                                          │
│  【情况2】x 的兄弟 w 是黑色，且 w 的两个孩子都是黑色     │
│  ┌──────────────────────────────────────────────────┐ │
│  │                                                  │ │
│  │   修复前：              修复后：                  │ │
│  │                                                  │ │
│  │       [p]?                 [p]?                   │ │
│  │      /    \              /    \                  │ │
│  │    [x]B    [w]B        [x]B    [w]R              │ │
│  │            /  \                /  \              │ │
│  │          [a]  [b]B          [a]  [b]B             │ │
│  │                                                  │ │
│  │  操作：                                          │ │
│  │  1. w 涂红                                       │ │
│  │  2. x = p（向上回溯）                            │ │
│  │  3. 继续处理                                     │ │
│  │                                                  │ │
│  └──────────────────────────────────────────────────┘ │
│                                                          │
│  【情况3】x 的兄弟 w 是黑色，w 的左孩子是红色，右是黑色 │
│  ┌──────────────────────────────────────────────────┐ │
│  │                                                  │ │
│  │   修复前：              修复后：                  │ │
│  │                                                  │ │
│  │       [p]?                 [p]?                   │ │
│  │      /    \              /    \                  │ │
│  │    [x]B    [w]B        [x]B    [a]R              │ │
│  │            /  \                /  \              │ │

def delete_fixup(self, x):
    """
    删除修复算法
    """
    while x != self.root and x.color == 'B':
        # 情况A：x 是左孩子
        if x == x.parent.left:
            w = x.parent.right  # w = 兄弟节点
            
            # 情况1：兄弟是红色
            if w.color == 'R':
                w.color = 'B'           # 兄弟涂黑
                x.parent.color = 'R'   # 父节点涂红
                self.left_rotate(x.parent)
                w = x.parent.right     # 更新兄弟
            
            # 情况2：兄弟是黑色，且两个孩子都是黑色
            if w.left.color == 'B' and w.right.color == 'B':
                w.color = 'R'          # 兄弟涂红
                x = x.parent           # 向上回溯
            
            else:
                # 情况3：兄弟是黑色，左孩子红，右孩子黑
                if w.right.color == 'B':
                    w.left.color = 'B'  # 左孩子涂黑
                    w.color = 'R'      # 兄弟涂红
                    self.right_rotate(w)
                    w = x.parent.right  # 更新兄弟
                
                # 情况4：兄弟是黑色，右孩子红
                w.color = x.parent.color    # 兄弟涂成父节点颜色
                x.parent.color = 'B'        # 父节点涂黑
                w.right.color = 'B'         # 右孩子涂黑
                self.left_rotate(x.parent)
                x = self.root               # 完成
        
        # 情况B：x 是右孩子（镜像处理）
        else:
            w = x.parent.left   # w = 兄弟节点
            
            # 情况1：兄弟是红色
            if w.color == 'R':
                w.color = 'B'
                x.parent.color = 'R'
                self.right_rotate(x.parent)
                w = x.parent.left
            
            # 情况2：兄弟是黑色，且两个孩子都是黑色
            if w.left.color == 'B' and w.right.color == 'B':
                w.color = 'R'
                x = x.parent
            
            else:
                # 情况3：兄弟是黑色，右孩子红，左孩子黑
                if w.left.color == 'B':
                    w.right.color = 'B'
                    w.color = 'R'
                    self.left_rotate(w)
                    w = x.parent.left
                
                # 情况4：兄弟是黑色，左孩子红
                w.color = x.parent.color
                x.parent.color = 'B'
                w.left.color = 'B'
                self.right_rotate(x.parent)
                x = self.root
    
    x.color = 'B'  # 保证 x 是黑色

def delete(self, key):
    """
    删除节点
    """
    # 找到要删除的节点
    z = self._search(self.root, key)
    if z == self.NIL:
        return False
    
    y = z  # y 记录要删除的原始节点
    y_original_color = y.color  # 记录原始颜色
    
    # ========== 三种删除情况 ==========
    if z.left == self.NIL:
        # 情况A：z 没有左子节点
        x = z.right
        self._transplant(z, z.right)
    elif z.right == self.NIL:
        # 情况B：z 没有右子节点
        x = z.left
        self._transplant(z, z.left)
    else:
        # 情况C：z 有两个子节点
        y = self._minimum(z.right)  # 找后继
        y_original_color = y.color
        x = y.right
        
        if y.parent == z:
            x.parent = y
        else:
            self._transplant(y, y.right)
            y.right = z.right
            y.right.parent = y
        
        self._transplant(z, y)
        y.left = z.left
        y.left.parent = y
        y.color = z.color
    
    # 如果删除的是黑色节点，需要修复
    if y_original_color == 'B':
        self.delete_fixup(x)
    
    return True

def _transplant(self, u, v):
    """用 v 替换 u"""
    if u.parent == self.NIL:
        self.root = v
    elif u == u.parent.left:
        u.parent.left = v
    else:
        u.parent.right = v
    v.parent = u.parent

def _search(self, node, key):
    """查找节点"""
    while node != self.NIL and key != node.key:
        if key < node.key:
            node = node.left
        else:
            node = node.right
    return node

def _minimum(self, node):
    """找最小节点"""
    while node.left != self.NIL:
        node = node.left
    return node
```

## 13.7 常见面试题与FAQ

### ❓ FAQ 1：为什么根节点必须是黑色？

**答**：根节点涂成黑色是为了统一所有路径的黑色高度计算。如果根节点可以是红色，那么空树（根=NIL）和非空树在黑色高度的起始点就会不一致，不利于性质5的统一。

**更深层的理解**：
- NIL节点是黑色
- 如果根可以是红色，那么根→NIL路径的黑色高度是0
- 但根→叶子路径的黑色高度至少是1
- 这会导致性质5"所有路径黑色高度相同"无法统一

### ❓ FAQ 2：为什么红黑树的高度最多是 2log₂(n+1)？

**答**：这是由红黑树的5条性质共同保证的。

**证明关键点**：
1. 将红黑树中的红色节点"收缩"到其黑色父节点下
2. 收缩后，所有路径长度相同（黑色高度）
3. 每个黑色节点至少有两个子节点（否则需要旋转修复）
4. 这形成了一棵满二叉树
5. n 个节点的满二叉树高度 ≈ log₂(n+1)
6. 原始红黑树高度 ≤ 2 × 黑色高度 ≤ 2log₂(n+1)

### ❓ FAQ 3：删除操作为什么要记录"原始颜色"？

**答**：因为修复策略取决于被删除节点的颜色。

**关键洞察**：
- 删除**红色**节点：不会破坏性质5（黑色高度不变），最多违反性质4
- 删除**黑色**节点：必然破坏性质5，需要修复

所以删除后要检查被删除节点的原始颜色：
- 如果是红色：直接完成
- 如果是黑色：调用 DELETE-FIXUP 修复

### ❓ FAQ 4：红黑树和AVL树的核心区别是什么？

**答**：

| 特性 | 红黑树 | AVL树 |
|:--:|:--:|:--:|
| 平衡策略 | 近似平衡（最长≤2×最短） | 严格平衡（差值≤1） |
| 插入调整 | ≤2次旋转 | ≤1次旋转 |
| 删除调整 | ≤3次旋转 | ≤O(log n)次旋转 |
| 查找性能 | 略低（高度略大） | 更高（更平衡） |
| 综合性能 | 插入/删除多时更优 | 查找多时更优 |

**实战建议**：
- 需要频繁插入/删除：选红黑树
- 需要严格有序查找：选AVL树
- 大多数场景：选红黑树（C++ STL的选择）

### ❓ FAQ 5：为什么STL选择红黑树而不是AVL树？

**答**：

```
